# 📚 Ciberseguridad para todos

Bienvenido al repositorio oficial del curso gratuito **"Ciberseguridad para todos"**, dictado por Marcelo Bugallo (a.k.a. DarthChelo) en el canal de YouTube **[Tu Defensa Digital](https://www.youtube.com/@TuDefensaDigital)**.

Este espacio está diseñado para complementar las clases en video. Aquí encontrarás los apuntes teóricos, *Cheat Sheets* (hojas de resumen) y los laboratorios prácticos de cada módulo, pensados para democratizar la seguridad de la información tanto para usuarios finales como para PyMEs.
